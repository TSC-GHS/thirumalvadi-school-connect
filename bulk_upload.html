📖 Upload Guidelines

  1. Select Upload Type.
  2. Download the CSV Template.
  3. Fill data in Excel.
  4. Keep EMIS & Mobile columns as TEXT.
  5. Date Format : YYYY-MM-DD
  6. Attendance Status : P / A / L / OD
  7. Save file as CSV UTF-8.
  8. Select file.
  9. Click Upload.
  10. Verify Import Summary.
