CSV Format Guidelines
  • EMIS, Mobile Number → Format as Text
  • Date Format → YYYY-MM-DD
  • Attendance Status → P / A / L / OD
  • Student Status → Active / Inactive
  • Teacher Status → Active / Inactive
  • Exam Names → Unit Test 1, Unit Test 2, Quarterly, Half Yearly, Revision Test, Model Exam, Public Exam
  • Do not change column names.
  • Do not delete any mandatory columns.
  • Save file only in CSV format.
